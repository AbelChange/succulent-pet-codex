# 发布与分享说明

## 适用范围

肉肉包含 9 种标准动作和 16 个视线方向，使用本机 hatch-pet v2 资源规范。安装脚本仅支持 macOS；客户端需支持本地 v2 宠物。网页端不会自动读取本地安装文件。

天气自动联动不属于标准动画包，相关探索保留在 `feat_dynamic_weather` 分支。

## 发布前确认

- 在目标客户端确认肉肉可被选择、显示及播放动作。
- 检查 `pet/SHA256SUMS`、预览图及安装说明与待发布资源一致。
- 确认拥有所含参考图和角色素材的分享授权。
- 发布包包含 `LICENSE`；仅允许非商业使用，修改和分享需保留许可、署名并标明修改。

## 分享方式

推送准备好的提交后，可分享仓库链接；需要固定版本时创建版本标签和 GitHub Release，将包含安装脚本、`pet/`、README 和 LICENSE 的 ZIP 作为附件。

用户下载解压后执行 `bash install.sh`，再在客户端宠物选择界面刷新并选择「肉肉 RouRou」。脚本不覆盖已有肉肉，也不会自动启用它。

仓库改名不会自动发布新版安装包。只有完成推送、创建 Release 后，才能说明对应版本已发布。
