# 安装后不显示的排查方法

此安装脚本仅支持 macOS，安装到 `${CODEX_HOME:-$HOME/.codex}/pets/rourou`，不会自动选择宠物，也不会覆盖已有肉肉或其他宠物。

1. 从主分支下载 ZIP，在包含 install.sh、LICENSE、pet/ 的解压目录执行 `bash install.sh`，不要使用 sudo。
2. 安装成功后，在支持本地自定义宠物的桌面客户端刷新宠物列表，选择「肉肉 RouRou」，再用 `/pet` 显示。
3. 如果没有刷新入口或列表仍未更新，完全退出应用再重新打开。不同客户端版本的入口名称可能不同。
4. 若提示肉肉已存在，先检查已有资源，不要删除或覆盖。这个提示并不表示已经选择或显示宠物。
5. 确认终端和客户端使用相同的系统用户及 CODEX_HOME。本地文件安装不会自动同步到网页端。
6. 客户端需要支持本地 v2 宠物；目前未确认最低兼容版本。没有宠物入口时，请先检查客户端版本和功能可用性。

## 验证安装资源（macOS，只读）

```bash
pet_dir="${CODEX_HOME:-$HOME/.codex}/pets/rourou"
printf '检查路径：%s\n' "$pet_dir"
ls -l "$pet_dir/pet.json" "$pet_dir/spritesheet.webp"
/usr/bin/plutil -convert xml1 -o /dev/null "$pet_dir/pet.json"
/usr/bin/plutil -extract spriteVersionNumber raw -o - "$pet_dir/pet.json"
/usr/bin/plutil -extract spritesheetPath raw -o - "$pet_dir/pet.json"
/usr/bin/sips -g pixelWidth -g pixelHeight "$pet_dir/spritesheet.webp"
/usr/bin/shasum -a 256 "$pet_dir/pet.json" "$pet_dir/spritesheet.webp"
```

预期：版本 2，图片路径 spritesheet.webp，尺寸 1536×2288；校验值应与仓库 pet/SHA256SUMS 一致。

旧安装脚本如果使用 `plutil -lint`，可能把合法 JSON 报为 `Unexpected character {`。当前主分支已使用 `plutil -convert xml1 -o /dev/null` 检查；请重新下载当前主分支，不要修改 pet.json 来绕过检查。

## 反馈问题时请提供

仓库链接、分支及下载日期、系统、客户端名称和版本、安装命令及完整输出，以及是列表找不到、无法选择还是选择后不显示。日志中的账号或令牌请隐去。
