# 肉肉动作与天气状态设计

日期：2026-10-08。角色以用户设定图为准：粉尖绿叶、圆脸、陶土盆、嫩芽标记。第一版主要采用盆栽形态，行走以花盆左右摇摆小跳表现；自由形态作为扩展参考。

## Codex 标准动作
|行|状态|帧数|肉肉动作|表情参考|
|---|---|---:|---|---|
|0|idle|6|呼吸、眨眼、叶片轻微摆动|01你好|
|1|running-right|8|朝右摇盆小跳、姿态交替|02早安|
|2|running-left|8|朝左摇盆小跳、姿态交替|02早安|
|3|waving|4|叶片小手抬起挥手并收回|04拜拜、15加油|
|4|jumping|5|蓄力、离地、顶点、落下、归位|05开心|
|5|failed|8|叶片下垂、低头委屈，眼泪贴脸|09哭哭、10委屈|
|6|waiting|6|双手靠盆沿、期待看向用户|12疑惑|
|7|running|6|专注思考、轻点叶片小手，表示任务处理中|13收到|
|8|review|6|前倾观察、歪头、认真眨眼|12疑惑、13收到|
|9–10|look|16方向|视线与头部连贯转向，盆体保持稳定|需新增|

running 表示任务处理，不表示奔跑。16方向按22.5度顺时针；000为向上，090向右，180向下，270向左。用户交互与任务状态优先，天气不打断关键状态。

## 天气状态与喜好
下列为拟人化产品设计规则，真实多肉品种和养护环境差异很大。温度分界只是可配置的初始设计值，不作为植物养护结论。

|天气条件|喜好/表情|动作|展示天气效果|正式宠物处理|
|---|---|---|---|---|
|温和晴天，约15–28°C|喜欢：05开心|闭眼享受、展开小手|柔和阳光|微笑与姿态；不放悬浮太阳|
|多云、温和|舒适：01你好|慢眨眼、轻摆叶片|柔云背景|保持安静待机|
|短暂小雨|好奇：12疑惑|歪头观察、举伞|少量雨点|伞柄连手；不放独立雨滴|
|持续大雨|不喜欢：10委屈|护盆、缩起身体|大雨场景|委屈与护盆动作|
|高温，初始≥32°C，或强烈日照提示|不适：08生气的轻度版本|疲倦眯眼、扇风|强阳光、热感|手持小扇需贴合轮廓；不做光晕|
|寒冷，初始≤5°C，或下雪|不喜欢：10委屈|围围巾、轻颤|雪景|围巾贴身；不放悬浮雪花|
|大风，初始≥10m/s|紧张：11震惊的轻度版本|抱住盆沿、微微压叶|风场景|叶片姿态表现风，不做风线|
|雷雨|不喜欢：11震惊|突然缩回盆内，再探头|远处闪电|惊讶动作，不做独立闪电|
|晴朗夜晚|安心：03晚安|闭眼、慢呼吸|月光背景|睡眠是扩展概念，不替换标准工作状态|

规则优先级：雷雨/极端天气 > 寒冷/高温 > 大风 > 持续大雨 > 小雨 > 温和晴天/多云。晴天并不总等于喜欢；降雨并不自动等于该浇水。未知、过期或无法获取天气时回到中性待机。

## 天气接口接入方案（未实施）
用户选择城市，保存城市名和坐标；无需自动获取精确位置。接口返回天气代码、温度、体感温度、风速、降水、昼夜与观测时间。建议30分钟刷新，缓存最近有效结果，超过2小时标记过期，出错保持中性状态。降雨持续性须结合多次观测或时段数据，不能仅凭一次天气代码推断。

完整天气图用于预览和发布展示。若运行环境允许，可用独立天气叠加层配合表情动画；已检查的 hatch-pet 资源规范仅定义固定动作和16视线方向，没有天气订阅或自动切换配置。能否在当前 Codex 中自动切换天气皮肤还需确认，不能仅添加 manifest 字段实现。若不支持，采用用户手动切换天气版本，或另做支持天气接口的桌面宠物运行程序。
