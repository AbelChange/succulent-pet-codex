# 肉肉 RouRou · Codex 桌面宠物

粉尖绿叶、陶土花盆的小多肉。已完成9种标准动作和16个视线方向，通过本机 hatch-pet v2 结构、透明度、方向及视觉检查。

![待机眨眼](previews/idle.gif)

## 本地安装
当前版本已在作者的 Mac 安装。应用内实际显示与切换需在目标版本确认。

下载仓库 ZIP 并解压，在目录内执行：

    bash install.sh

安装后打开 **设置 > Pets > Refresh（刷新）**，选择 **肉肉 RouRou**。脚本不会自动激活宠物，不需要 sudo，也不会覆盖已有的肉肉。

正式推送这个版本后，可使用下面的单命令下载并安装（需要 Git）：

    git clone https://github.com/AbelChange/rourou-codex-pet.git && bash rourou-codex-pet/install.sh

**此轮改动暂存本地，尚未推送；远端暂未包含正式动画包。** 后续公开版本建议使用固定标签。

## 动作
待机眨眼、向右移动、向左移动、挥手、小跳、失败反应、等待输入、任务处理中、检查结果，以及16个鼠标视线方向。触发与显示由客户端控制。

## 文件
- pet/：manifest、透明精灵图和 SHA-256 校验文件。
- previews/：各动作 GIF、完整预览和视线检查图。
- qa/：结构、透明边缘、视觉与独立方向复核报告。
- assets/：用户角色设定与16表情原图。
- docs/：动作清单、资源制作和客户端规范说明。
